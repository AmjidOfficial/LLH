# LLH AI Engine

Self-hosted GPU inference service for Legacy Leather House virtual try-on. Hatchable remains the source of truth for catalogue, inventory, users, consent, orders and customer history.

**Status: foundation scaffold only. Not deployed and not production-ready.** Generation is fail-closed until a pinned local VTON runtime is installed, audited and tested. No commercial try-on API is used.

See `docs/HATCHABLE-INTEGRATION.md` for the integration contract and security boundaries.
